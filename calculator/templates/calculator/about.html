About This Project

Work Record Management System

This Django application helps users manage daily work records, view history, generate PDF and Excel reports, and securely manage their accounts.

Features
  • User Login & Logout
  • Add, Edit and Delete Work Records
  • Search Work History
  • Export Reports to PDF & Excel
  • Password Change
  • Responsive Bootstrap Interface
Technology Stack
  • Python
  • Django
  • Bootstrap
  • SQLite

Version 1.0
Developed using Django Framework.
