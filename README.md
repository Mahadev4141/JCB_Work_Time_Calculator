# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/JCB_Work_Time_Calculator.git
```

Go to project

```bash
cd JCB_Work_Time_Calculator
```

Create Virtual Environment

```bash
python -m venv venv
```

Activate Virtual Environment

Windows

```bash
venv\Scripts\activate
```

Install Requirements

```bash
pip install -r requirements.txt
```

Run Migrations

```bash
python manage.py migrate
```

Start Server

```bash
python manage.py runserver
```
